# MakerWorld Automatic Verification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically complete supported MakerWorld GeeTest icon-click, GeeTest slider, and browser-native Turnstile challenges inside the existing CloakBrowser-backed 3MF authorization page, with at most two provider interactions and a safe manual fallback.

**Architecture:** Keep Puppeteer and the existing CloakBrowser profile as the sole browser owner. Add a short-lived local OpenCV recognizer that accepts only bounded in-memory PNG data, add a focused JavaScript provider coordinator for challenge discovery and input, and let the existing bridge consume only page-generated `/f3mf` retries after its single Download 3MF click.

**Tech Stack:** Python 3.11, `opencv-python-headless==4.13.0.92`, NumPy, Puppeteer Core 24, Node 20 `node:test`, existing Python `unittest`/pytest, Docker Compose.

## Global Constraints

- The Download 3MF action is clicked exactly once per authorization operation.
- Provider interaction is attempted at most twice and the automatic phase is capped at 50 seconds.
- MakerHub never replays the `/f3mf` request itself; only a retry generated by the current page is accepted.
- `MAKERHUB_AUTO_VERIFY_3MF` defaults to `false`; the maintained DSM instance enables it explicitly for live acceptance.
- Screenshots, target symbols, puzzle pieces, provider tokens, cookies, and raw challenge responses are never persisted or logged.
- Low confidence, unsupported layout, timeout, or provider rejection returns the original verification response and preserves the existing manual browser flow.
- A verification failure never changes an otherwise valid account to login-expired.
- Existing `videos/makerhub-intro/output/` worktree content is unrelated and must not be staged.

        cv2.rectangle(image, (14, 40), (82, 56), color, -1)
    else:

MAX_IMAGE_BYTES = 4 * 1024 * 1024
MAX_IMAGE_DIMENSION = 2048
MAX_CANDIDATES = 6
CLICK_CONFIDENCE_MIN = 0.70
CLICK_MARGIN_MIN = 0.08
SLIDER_CONFIDENCE_MIN = 0.72
SLIDER_MARGIN_MIN = 0.06


def _decode_png(raw: bytes) -> np.ndarray:
    if not raw or len(raw) > MAX_IMAGE_BYTES:
        raise ValueError("image_size_invalid")
    image = cv2.imdecode(np.frombuffer(raw, dtype=np.uint8), cv2.IMREAD_UNCHANGED)
    if image is None or image.ndim not in {2, 3}:
        raise ValueError("image_decode_failed")
    height, width = image.shape[:2]
    if min(width, height) < 8 or max(width, height) > MAX_IMAGE_DIMENSION:
        raise ValueError("image_dimensions_invalid")
    return image

    # Decode, extract alpha/dark foreground, remove border components, crop,
    # normalize to a 96x96 canvas, and score binary IoU + Hu moments + edge overlap.
    # Return only candidate_index, confidence, margin, and a bounded reason.
